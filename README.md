# Nexvia Technologies – Data Science Internship

This repository contains two Data Science projects developed as part of my internship at **Nexvia Technologies**.

The projects focus on applying Machine Learning, Deep Learning, Predictive Analytics, Time-Series Forecasting, and Optimization techniques to solve real-world business problems.

---

## Project 1: Customer Lifetime Value and Churn Intelligence System (DS-01)

### Overview

Develop an intelligent customer analytics system to predict customer churn, estimate Customer Lifetime Value (CLV), analyze customer survival probabilities, and identify effective customer retention strategies.

### Key Objectives

- Analyze customer behavior and identify churn patterns.
- Develop machine learning models for customer churn prediction.
- Estimate customer survival probabilities.
- Perform customer lifetime value estimation.
- Apply uplift modelling to evaluate retention strategies.
- Develop an interactive ROI simulation application.

### Technologies

Python, Pandas, NumPy, LightGBM, SHAP, Lifelines, CausalML, PostgreSQL, Streamlit.

---

## Project 2: Nationwide Demand Forecasting and Inventory Optimization (DS-02)

### Overview

Develop an intelligent demand forecasting and inventory optimization system to predict product demand across multiple stores and geographical locations, helping businesses minimize stockouts and excess inventory.

### Key Objectives

- Analyze historical retail sales data.
- Identify seasonal trends and demand patterns.
- Develop machine learning and deep learning forecasting models.
- Implement hierarchical demand forecasting.
- Generate prediction intervals to measure forecasting uncertainty.
- Optimize inventory and replenishment quantities.
- Develop an interactive forecasting and inventory dashboard.

### Dataset

Walmart M5 Forecasting Dataset.

### Technologies

Python, Pandas, NumPy, Prophet, LightGBM, Darts, PyTorch Forecasting, Google OR-Tools, Plotly, Dash.
